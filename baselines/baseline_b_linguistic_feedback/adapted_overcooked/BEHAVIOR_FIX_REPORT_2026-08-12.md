# Agent 行为回归修复（2026-08-12）

## 问题

最新一局实际运行的是 `frozen` 对照模式，因此语言只被记录，没有在线更新。该局还暴露了真实策略回归：AI 在锅口连续 WAIT 44 步，67 步任务奖励为 0。

主要原因不是奖励更新公式，而是在线 `phi(state, subgoal)` 与可行集合不正确：

- WAIT 被错误标成“让路”，实际却堵住锅口；
- 锅还缺两个番茄、玩家只拿一个时，AI 再拿番茄被误判成重复劳动；
- 多锅状态被压缩成单锅，可能遗漏另一锅的缺料工作；
- 只检查下一动作是否为 STAY，无法发现两格往返但任务无进展的循环；
- 提前拿到暂时无用的物品后，没有通用的放下动作。

## 修复

- 用真实人数、剩余数量、目标重叠和通道几何计算协作特征；WAIT 不再按名称获得让路奖励。
- 保留所有锅的状态，支持 ready/partial、cooking/partial 同时存在。
- 运动上不可执行的候选先从可行集合删除，剩余候选仍严格按 `w·phi` 排序。
- 对无任务进展的 WAIT 和 A-B-A-B 运动循环施加可行性约束，不增加手工奖励。
- 新增通用 `STASH_HELD_OBJECT`，把暂时无用物品放到实时空台面；原 H0 神经网络的 8 维输入契约未改变。
- 合法烹饪等待保留；如果 AI 正堵住锅口或出餐口，则不享受等待豁免。
- Route 1/Route 2 存档改为完整校验后原子恢复；模型、53 维 schema、精度、更新规则或基础权重不一致时拒绝恢复且不污染当前状态。
- `frozen` UI 现在醒目标明“只记录，不学习”，不会再输出会在线改进的误导回复。

语言只改变奖励权重；除任务可执行性与防死循环约束外，最终选择仍是 `argmax w·phi`，没有把“预取番茄/洋葱”写成反馈规则。
