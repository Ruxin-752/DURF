# DURF 项目周报（2026-08-27）

## 本周概况

本周继续改进语言反馈三分类，把 Route1 按原论文链路重新梳理，检查 Route2，并推进能远程体验、使用随机参与者编号收集研究数据的 Web 版。界面变得更清楚、更像 2D 像素厨房，但原地图布局及锅、菜、灶台、出餐口和出生点均不移动。

## 1. 三分类与准确率

三分类仍只判断 Evaluative（评价）、Imperative（指令）和 Descriptive（描述）。模型现已冻结，避免看过测试结果后继续调参。论文风格代理开发集为 92/99，准确率 92.93%，宏平均 F1 为 92.59%；混合开发集准确率 90.65%；已使用过的论文人工语句代理回归集为 88/96，准确率 91.67%，宏平均 F1 为 88.96%。现有代理数据已达到 87% 目标，但 91.67% 不能写成真实玩家准确率：它不是新的封存盲测，也不是当前玩家自然语言。真实准确率要等 Web 版收集独立真人标注后再报告。界面现在展示三类完整概率，并使用固定的校准参数和拒绝阈值；低置信度输入会明确拒绝。

## 2. Route1 按论文链路解耦

Pygame 的 Route1 已统一为：语言 u → 三类反馈 fG → 目标特征 f → 正负情感 ζ → 贝叶斯公式更新权重 w。评价类使用最近轨迹特征，指令类使用被要求动作的特征，描述类使用文本明确提到的特征。原来的五类 classifier 只保留为三类内部的细分路径，不能改写三分类结果。细分类冲突时会记录并回到三分类允许的路径；目标不明确、类别未知或置信度过低时拒绝更新。Web 端目前能展示并计算这条链，但反馈权重还没有真正接入浏览器 AI 的子目标选择，因此不能说 Web Route1 已与 Pygame 完全一致。

## 3. Route2 检查结果

Pygame Route2 的代码链路符合当前论文实现：原始语言与已执行轨迹进入十模型集成，得到 53 维权重估计，再做独立高斯后验更新并重排候选行为。十个模型及版本绑定、重复事件保护和恢复逻辑均已核对。但一次独立手写自然语言小样本检查仅 1/4 正确；样本太少，不能作为正式准确率，却说明真人表达泛化仍有风险。Web 版目前能运行冻结的十模型和高斯更新，但尚未用更新权重控制 Web AI，因此仍标为实验功能。

## 4. 界面、地图与 Web 数据采集

界面优化重点是避免文字、概率和游戏画面互相遮挡，Web 可见文字已统一成英文。玩家可见的 Route1/Route2 选择和技术 trace 已移除，但两条后台算法仍保留；三类概率和置信度继续显示。两位厨师也换成了更精细的原创 CSS 像素形象，用不同制服、发型、围巾、围裙和面部细节区分玩家与 AI。美术只改变外观和面板，不改原 `.layout` 的格子、墙面、锅、食材、出餐口与出生点；Web 版逐格复制同一布局，并用坐标测试防止误改。本周还补齐了 2 Hz 人机联合动作，玩家和 AI 都在同一个 500 毫秒步进中最多移动一格；同时加入柜台放取、碰撞、20 步烹饪、+20 奖励、800 步回合，以及会冻结时间、锅、AI 和待执行输入的 Pause。Web 研究体验版在首次开局前取得知情同意，使用随机参与者编号记录逐步轨迹、原始反馈、完整概率和模型版本，并通过断线队列批量上传到 D1；服务端有短期会话令牌、同源检查、限流以及重复/冲突识别。研究表不主动写入姓名、邮箱或原始 IP，也没有邮件和邀请功能；训练数据导出需要管理员令牌。公开网址：[DURF Kitchen Lab](https://durf-kitchen-lab-study.xc3083.chatgpt.site)。

新增的离线更新链路会把 D1 导出转换成不含模型预测的盲标任务，再由人工审核三类标签。训练、开发和冻结测试按参与者、会话和相同文本隔离；持久 split registry 保证后续新增数据不会把旧冻结样本移入训练集。模型通过冻结评测和人工审批后，才导出新的浏览器 artifact；网页按 manifest 加载，并在使用前核对 SHA-256。线上预测不会被当作训练答案，网页也不会边玩边自动替换生产模型。

## 5. 验证情况与下周计划

桌面 Pygame 通道保持独立，本轮复测基线 70 项、Group A/UI 31 项全部通过；此前 Route2 110 项也通过。适配模块此前共检查 224 项，其中 6 项只是 Windows 临时目录权限问题，换到允许目录后均通过。Web 端 84 项测试、类型检查、代码检查和生产构建全部通过，新增数据转换器 7 项测试也全部通过；地图字符、出生点、设施坐标、人和 AI 对四类物品的柜台放取、8 种三食材顺序、碰撞、锅、奖励、回合和 Pause 都有回归测试。真实浏览器又完成了英文界面、Pause/Resume、隐藏技术路线 UI 和新版厨师视觉验收，页面没有框架报错或遮挡。
