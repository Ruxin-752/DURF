# DURF Archive

This folder keeps legacy or reference material that is not part of the current
active implementation path. Files are archived rather than deleted so they can
be restored if needed.

## Current Active Path

- `durf/baseline/`: RLlib PPO baseline loading, evaluation, and viewing.
- `durf/group_a/play_with_baseline.py`: human + PPO pygame collaboration and
  session logging.
- `durf/group_b/`: reserved for the new LLM-assisted feedback attribution work.

## Archived Material

- `legacy_scalar_feedback/`
  - Standalone scalar keyboard listener and example output files.
  - This was useful for early J/K feedback testing but is not the main research
    path now.
- `legacy_notebooks/`
  - Original tutorial notebooks kept for reference.
